# Kling v3 (Kuaishou, on fal) — how to prompt it

Condensed from fal's "Kling 3.0 Prompting Guide" (blog.fal.ai/kling-3-0-prompting-guide), Kling's
own VIDEO 3.0 model guide (kling.ai/quickstart/klingai-video-3-model-user-guide) and the fal
endpoint page for fal-ai/kling-video/v3/standard/image-to-video (all read 2026-10-09).

## How the request runs
- `start_image_url` is frame one; `end_image_url` (optional) is the last frame.
- Audio is generated by default (`generate_audio: true`). Speech in English and Chinese; other
  languages are translated to English. For English speech, write the line in normal case and keep
  capitals for names and acronyms.
- The endpoint has a separate `negative_prompt` (default "blur, distort, and low quality") and
  `cfg_scale` (0-1, default 0.5: how strictly it follows the prompt). Unwanted things belong in
  the negative prompt, not the main prompt.
- Durations 3-15 s. Multi-shot (up to six labelled shots) exists but Red Clover generates one shot
  per clip.

## What to write (image-to-video)
- Treat the image as the anchor: it keeps identity, layout and any text. Describe what CHANGES —
  the subject's movement, the camera's movement, the environment — not what the image shows.
- Write it as direction for a scene, in film language, not a list of objects. Order: setting and
  light (only if it changes), subject and action, then one camera behaviour, then sound.
- One camera move per shot (tracking, push in, pull back, pan, tilt, orbit, handheld, locked
  off). Several moves in one shot belong in several shots. Say how the camera relates to the
  subject over time ("stays in a medium shot as she walks, holds when she stops").
- Dialogue: describe the action first, then the line, so the model attaches it to the right
  person. Speaker, delivery in brackets, colon, line:
  `The woman inside (tired, flat): "What do YOU want?"`
  With two speakers, give each a unique visual label and keep it identical every time
  (`[the red-haired woman in the fringed jacket]`), never a pronoun. Use "Immediately," between
  lines to stop them merging.
- Sound: ambient and action sounds as plain sentences ("Rain on the window. A chair scrapes.").

## What goes wrong
- Red Clover's Kling v3 test on 5b (2026-10-09) was the weakest of the models tried; prefer it
  for simple single-subject motion.
- Vague prompts with no motion, chaotic multi-character action, and start/end frames with very
  different subjects or compositions all degrade results.
